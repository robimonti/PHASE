# Legacy App Designer applications

This directory preserves the former PHASE `.mlapp` applications for
reproducibility and source provenance:

- `PHASE_Preprocessing.mlapp`
- `PHASE_Preprocessing/PHASE_StaMPS.mlapp`
- `PHASE_model.mlapp`

They are no longer used by the production runtime or Windows installer. The
supported applications are the editable standalone MATLAB launchers in the
repository root and `PHASE_Preprocessing` directory.

`install-phase-pre-v6.exe` is the obsolete pre-v6 compiled installer retained
only for provenance. Windows users must download the current installer from the
latest GitHub Release and must not run this archived executable.

Do not copy these MLAPP files into a current installation. They remain here
only to reproduce the extracted editable engines and to inspect historical
projects.
